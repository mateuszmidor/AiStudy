# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| **hwinfo** | `glossary/business.md` | Names the binary and tool throughout the design; the diagram's container is this one binary. |
| **total physical memory** | `glossary/business.md` | The quantity the read returns. The design is careful never to imply usage, availability, or free memory, all of which are explicit non-goals. |
| **GB** | `glossary/technical.md` | The unit of the printed value, meaning 1024³ bytes; it is the reason decision 7 and the truncation risk are written the way they are. |
