# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| **hwinfo** | `glossary/business.md` | Names the tool this capability belongs to, in the spec's Purpose. |
| **total physical memory** | `glossary/business.md` | The quantity every requirement and scenario is about; the spec never says "memory usage", "available memory", or "used memory". |
| **GB** | `glossary/technical.md` | The unit the printed value is expressed in, meaning 1024³ bytes, which is why the truncation scenario counts in whole 1024³ units. |
