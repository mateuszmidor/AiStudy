# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| **hwinfo** | `glossary/business.md` | Names the product this change introduces; the repository, binary, and tool are all referred to as **hwinfo**, never as HWInfo or hw-info. |
| **total physical memory** | `glossary/business.md` | The single quantity this change reports. Used instead of "installed RAM" in structured prose and instead of "memory usage", "available memory", or "used memory", none of which this change reports. |
| **GB** | `glossary/technical.md` | The unit label printed for the total, meaning 1024³ bytes so the number matches what macOS shows for the same machine. Not GiB, and not the SI gigabyte of 1000³. |
